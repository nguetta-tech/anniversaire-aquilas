AQUILAS — HAPPY BIRTHDAY SITE
=============================

Démarrer :
1. Extraire le ZIP.
2. Ouvrir le dossier anniversaire_aquilas.
3. Double-cliquer sur index.html, ou ouvrir le dossier dans VS Code + Live Server.

Fichiers :
- index.html : contenu
- style.css : design responsive orange, crème et noir
- script.js : étoiles, confettis, boutons et son synthétique
- assets/aquilas.webp : photo fournie pour personnaliser la page

Le site fonctionne hors ligne pour ses fonctionnalités. Les polices Google nécessitent une connexion.
La photo reste locale dans le dossier assets : ne la supprime pas si tu veux l'afficher.
